# Сервер HeadsetConnector на телефоне — простая инструкция

Телефон будет работать как маленький сервер дома. Компьютер не нужен.
Телефон должен лежать на зарядке и быть в той же Wi-Fi, что и шлем.

---

## Шаг 1. Поставить Termux

Termux — приложение, внутри которого живёт сервер.

1. На телефоне открой браузер и зайди:
   <https://github.com/termux/termux-app/releases>
2. Скачай файл **termux-app_v…-universal.apk** (первый в списке Assets).
3. Открой скачанный файл. Телефон спросит «Разрешить установку из этого
   источника?» — разреши и нажми «Установить».

То же самое для автозапуска:

4. Зайди: <https://github.com/termux/termux-boot/releases>
5. Скачай **termux-boot-app_v…-universal.apk**, установи.
6. Открой **Termux:Boot** один раз и закрой (больше он не нужен).

---

## Шаг 2. Перекинуть архив на телефон

Файл: `HeadsetConnector-СЕРВЕР-НА-ТЕЛЕФОН.zip`

Самый простой способ — отправить его себе в Telegram «Избранное» и скачать
на телефоне. Или скопировать по USB в папку `Download`.

---

## Шаг 3. Установить сервер

1. Открой **Termux** (чёрное окно с текстом).
2. Нажми и удерживай палец в окне → **Paste** (вставь) эту строку:

```bash
termux-setup-storage; pkg install -y unzip nodejs; cd ~; unzip -o ~/storage/downloads/HeadsetConnector-СЕРВЕР-НА-ТЕЛЕФОН.zip -d hc-setup; bash hc-setup/install.sh
```

3. Нажми Enter. Появится вопрос про доступ к файлам — разреши.
4. Подожди 1–3 минуты, пока скачается Node.js. В конце появится слово
   **Готово** и адрес вида `http://192.168.1.42:8787`.

---

## Шаг 4. Запустить сервер

В том же окне вставь и нажми Enter:

```bash
bash ~/headsetconnector/start.sh
```

Появится:

```
HeadsetConnector server на порту 8787
  http://192.168.1.42:8787
  Пароль для панели /admin: Ab3xY9kLm
```

**Запиши адрес и пароль.** Это и есть твой сервер и вход в панель.

Свернуть Termux можно кнопкой «Домой» — сервер продолжит работать.
Закрывать Termux (свайпом из списка задач) нельзя.

---

## Шаг 5. Проверить

На этом же телефоне открой браузер и зайди:

```
http://192.168.1.42:8787/admin
```

Введи пароль из Шага 4. Увидишь панель: пользователи, сообщения, комнаты.

---

## Шаг 6. Подключить шлем

1. Установи на шлем `HeadsetConnector-0.1.apk`.
2. Открой приложение.
3. В поле адреса введи `http://192.168.1.42:8787` (свой адрес из Шага 4).
4. Создай аккаунт.
5. Второй аккаунт — на втором шлеме или телефоне, тот же адрес. Добавьте друг
   друга по юзернейму.

---

## Шаг 7. Чтобы сервер не выключался

1. **Настройки → Приложения → Termux → Батарея → Без ограничений**
   (на разных телефонах называется по-разному: «Не ограничивать»,
   «Разрешить фоновую работу»).
2. На Xiaomi/Redmi дополнительно: **Автозапуск** для Termux.
3. Перезагрузи телефон. Сервер должен подняться сам (через Termux:Boot).
   Проверка: открой Termux и введи `tail -f ~/headsetconnector/server.log`,
   должны идти строки.

---

## Если что-то не так

| Что видишь | Что делать |
|---|---|
| `unzip: command not found` | Введи `pkg install -y unzip` и повтори Шаг 3 |
| `No such file or directory` про zip | Архив лежит не в Download. Найди его: `find ~/storage -name "HeadsetConnector*"` и распакуй оттуда |
| `node: command not found` | Введи `pkg install -y nodejs` |
| Панель не открывается с ПК | Телефон и ПК в разных Wi-Fi, или IP телефона другой |
| После перезагрузки сервер не поднялся | Открой Termux:Boot один раз и проверь настройки батареи |
| Телефон убивает Termux | Отключи оптимизацию батареи и «умное энергосбережение» для Termux |

---

## Полезно знать

- Адрес телефона может смениться после перезагрузки роутера. Чтобы этого не
  было, закрепи IP за телефоном в настройках роутера (DHCP reservation).
- Все данные (аккаунты, сообщения, фото, голосовые) лежат в
  `~/headsetconnector/data` — это и есть бэкап.
- Остановить сервер: в Termux нажми Ctrl+C.
